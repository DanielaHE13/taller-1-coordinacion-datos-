
# E2 · Informe técnico

Este directorio está destinado al informe técnico del proyecto en PDF, correspondiente al entregable **E2**. La extensión requerida es de **6 a 8 páginas**.

El informe debe presentar el problema y los objetivos del taller, la arquitectura y las decisiones de diseño, los resultados de las pruebas y las conclusiones. Para respaldar los resultados, consulta el [índice de evidencias](../evidencias/README.md) y los registros de ejecución.

Cuando esté disponible, incorpora aquí el PDF final. Este README describe el propósito del directorio; no reemplaza el informe.
